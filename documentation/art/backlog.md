# Art backlog

Art still to make, roughly in order of how much it would improve the game.
Specs for each asset type are in `README.md`.

## Characters

- [ ] **Hand-drawn player layers** in Aseprite to replace the generated
      ones: body, eyes, the three hairstyles, three tops, two bottoms,
      shoes, two hats. Same 7×5 layout; the generated sheets show which pose
      goes in which frame.
- [ ] **Running row**: the walk with the body leaning forward (currently
      running reuses the walk).
- [ ] **Tool animations**: hoe swing, watering, axe chop (needed for tree
      chopping), harvesting/picking up.
- [ ] **More wardrobe pieces**: hairstyles (braid, ponytail, buzz), tops
      (hoodie, dress, apron), hats (straw hat, bandana), accessories
      (glasses, backpack).
- [ ] **NPC sprites**: shopkeeper, blacksmith, innkeeper, villagers. They
      can be built from the same paper-doll layers or drawn whole; NPCs only
      need 4 facings.

## World

- [ ] **Edge transitions** between path, grass and farmland (rounded
      corner tiles, chosen from neighbouring tiles). Currently every edge is
      a hard square.
- [ ] **Grass variants** (2–3 tiles) scattered to break the repetition.
- [ ] **Snow**: snow-covered grass, cliff tops and roofs, snowy pine
      (already drafted), for winter and snowy areas from the concept art.
- [ ] **Small props**: barrels, crates, signposts, lamp posts, campfire,
      fences in more styles, hay bales, wells, banners (original emblems,
      not Skyrim's).
- [ ] **Animals**: cows, chickens, a dog or cat; wild animals (deer, wolf)
      for the wilder areas.
- [ ] **Tree chopping**: stump, falling-tree frame, wood chips, sapling
      stages, wood and axe icons.
